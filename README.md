# .github

This repo provides the [FG-CollectLabs](https://github.com/FG-CollectLabs)
organization profile. The README rendered on the org page lives at
[`profile/README.md`](profile/README.md).

It will also house shared org-level GitHub assets over time:

- Issue and PR templates (`ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md`)
- Reusable GitHub Actions workflows (`workflow-templates/`)
- `FUNDING.yml`, `CODEOWNERS`, etc., when applicable

Per-repo overrides still win — anything here is just the default.
